# @residualhq/dsh

DeepSeek Harness plugin for Residual: layered compaction policy, a local dollar savings ledger, and an optional append-only tool gate.

This is not another coding-assistant shell. Prompts stay on the customer's machine. The package is not published yet; install from the monorepo checkout. See the repository root README for install, web vs headless enablement, settings, and the ledger.
